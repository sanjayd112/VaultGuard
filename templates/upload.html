What happens to your file

  1. ValidateExtension, MIME type, size and real file signature are checked.
  2. EncryptA fresh 96-bit nonce is generated and the file is sealed with AES-256-GCM.
  3. StoreOnly ciphertext is written, under a random identifier. The original is never saved.
  4. VerifySHA-256 digests are saved and the stored copy is decrypted once to prove it is intact.
